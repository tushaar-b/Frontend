1. PROJECT VISION & EXPERIENCE PRINCIPLES
================================================================================
- Concept: A tactile, living family memory vault where photographs, handwritten
  letters, train tickets, family recipes, and recorded voices interweave into an
  intimate tapestry.
- Emotional Atmosphere: Royal Indian dusk, ancestral courtyard warmth, reverent,
  editorial, cinematic, and physical. Memories feel like treasured ephemera held
  together by golden threads rather than cold, flat digital UI cards.
- Foundational Tenet: "A photograph keeps a moment. A voice brings it home."
- Core Motion Tenet: Continuous Identity. When moving between the hero scatter
  and the editorial section ("Some stories are still between the photographs"),
  never create duplicate or artificial transition cards. The exact wedding photo
  card from the hero cluster must magnify and glide directly into its final
  resting place in Section 01.

4. ATMOSPHERIC BACKGROUND CANVAS: FIREFLY PARTICLE SYSTEM
================================================================================
A self-contained HTML5 Canvas layer running on RequestAnimationFrame (RAF).
Sits behind the cards (z-index: 2) inside the sticky hero container.

Canvas Specifications:
- Particle Count: 50 particles (prominent and atmospheric)
- High-DPI / Retina Canvas support (`devicePixelRatio` scaled)
- Container: position: absolute; inset: 0; pointer-events: none; z-index: 2;
- Blend Mode: `ctx.globalCompositeOperation = "lighter"` (additive luminous optical glow)
- Multi-tier Color Palette:
  1. Warm Gold: `rgb(255, 210, 105)` (#FFD269)
  2. Deep Honey Amber: `rgb(249, 164, 54)` (#F9A436)
  3. Radiant Champagne: `rgb(255, 232, 160)`
  4. Soft Rose-Gold: `rgb(246, 184, 206)` (#F6B8CE)
- Particle Data Structure:
  {
    x: number (0 to canvas.width),
    y: number (0 to canvas.height),
    depth: 0.35 to 1.0 (depth layering),
    size: (1.6 to 3.8px) * depth,
    r, g, b: RGB color triplet from palette,
    baseAlpha: 0.55 to 0.95 (prominent baseline brightness),
    phase: 0 to 2*PI,
    phaseSpeed: 0.012 to 0.037,
    speedY: (0.18 to 0.58 px/frame) * depth,
    sineSpeed1, sineAmp1: primary harmonic oscillation,
    sineSpeed2, sineAmp2: secondary organic wander
  }

Animation Loop:
1. Clear canvas: `ctx.clearRect(0, 0, width, height)`
2. Set additive composite mode: `ctx.globalCompositeOperation = "lighter"`
3. For each firefly:
   - Upward float and dual-frequency waft:
     `f.y -= f.speedY;`
     `f.x += Math.sin(t * f.sineSpeed1 + f.phase) * f.sineAmp1 + Math.cos(t * f.sineSpeed2) * f.sineAmp2 + f.speedX;`
   - Seamless wrapping with 40px screen edge soft fade:
     `if (f.y < -30) { f.y = height + 20; f.x = Math.random() * width; }`
   - Organic bioluminescent power-curve breathing:
     `breath = Math.pow(Math.max(0, Math.sin(f.phase)), 1.6);`
     `f.alpha = f.baseAlpha * (0.22 + 0.78 * breath) * edgeFade;`
   - Render 4-stage optical bloom:
     a. Expansive soft atmospheric aura (radius: `f.size * (6.0 + 2.5 * breath)`)
     b. Focused warm mid halo (radius: `f.size * 2.6`)
     c. Hot incandescent spark core (radius: `f.size * 0.75`, `rgba(255, 255, 240, 1)`)
     d. Anamorphic lens flare cross-spikes during peak flash (breath > 0.65, depth > 0.6)

Deterministic Math Interpolations:
To prevent Framer Motion string interpolation parse errors, use functional transforms:

1. Focal Translation (Continuous 4-Phase Coordinates):
   useTransform(scrollYProgress, (p) => {
     let x = target.x, y = target.y;
     if (p <= 0.20) {
       const t = p / 0.20;
       x = stackOffset.x + (target.x - stackOffset.x) * t;
       y = stackOffset.y + (target.y - stackOffset.y) * t;
     } else if (p <= 0.25) {
       x = target.x; y = target.y;
     } else if (p <= 0.36) {
       const t = (p - 0.25) / 0.11;
       const ease = 1 - Math.pow(1 - t, 2);
       x = target.x * (1 - ease); y = target.y * (1 - ease);
     } else if (p <= 0.48) {
       const t = (p - 0.36) / 0.12;
       const ease = t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2;
       x = destX * ease; y = destY * ease;
     } else if (p <= 0.56) {
       x = destX; y = destY;
     } else if (p <= 0.68) {
       const t = (p - 0.56) / 0.12;
       const ease = t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2;
       x = destX * (1 - ease); y = destY * (1 - ease);
     } else if (p <= 0.72) {
       x = 0; y = 0;
     } else if (p <= 0.85) {
       const t = (p - 0.72) / 0.13;
       const ease = t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2;
       x = -destX * ease; y = destY * ease;
     } else {
       x = -destX; y = destY;
     }
     return `calc(-50% + ${x.toFixed(2)}vw) calc(-50% + ${y.toFixed(2)}vh)`;
   });

2. Focal Scale (Dual Peak Zoom):
   useTransform(scrollYProgress, (p) => {
     if (p <= 0.20) return stackScale + (restScale - stackScale) * (p / 0.20);
     if (p <= 0.25) return restScale;
     if (p <= 0.36) {
       const t = (p - 0.25) / 0.11;
       const ease = 1 - Math.pow(1 - t, 2);
       return restScale + (midScale - restScale) * ease;
     }
     if (p <= 0.48) {
       const t = (p - 0.36) / 0.12;
       const ease = t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2;
       return midScale + (1.0 - midScale) * ease;
     }
     if (p <= 0.56) return 1.0;
     if (p <= 0.68) {
       const t = (p - 0.56) / 0.12;
       const ease = t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2;
       return 1.0 + (midScale - 1.0) * ease;
     }
     if (p <= 0.72) return midScale;
     if (p <= 0.85) {
       const t = (p - 0.72) / 0.13;
       const ease = t < 0.5 ? 2 * t * t : 1 - Math.pow(-2 * t + 2, 2) / 2;
       return midScale + (1.0 - midScale) * ease;
     }
     return 1.0;
   });

3. Focal Rotation:
   useTransform(scrollYProgress, (p) => {
     if (p <= 0.20) return stackRotate + (endRotate - stackRotate) * (p / 0.20);
     if (p <= 0.25) return endRotate;
     if (p <= 0.36) return endRotate * (1 - (p - 0.25) / 0.11);
     if (p <= 0.48) return 2 * ((p - 0.36) / 0.12);
     if (p <= 0.56) return 2;
     if (p <= 0.68) return 2 * (1 - (p - 0.56) / 0.12);
     if (p <= 0.72) return 0;
     if (p <= 0.85) return -2 * ((p - 0.72) / 0.13);
     return -2;
   });

4. Normal Cards Fade & Display:
   normalOpacity = useTransform(scrollYProgress, (p) => {
     if (p <= 0.22) return 1;
     if (p <= 0.27) return 1 - (p - 0.22) / 0.05;
     return 0;
   });
   normalDisplay = useTransform(scrollYProgress, (p) => (p > 0.28 ? "none" : "block"));

9. CRITICAL ENGINEERING PITFALLS, BUGS & RULES OF PHYSICS
================================================================================
DO NOT MAKE THESE MISTAKES when replicating in another framework or project:

1. Never Pass String calc() Arrays to Framer Motion useTransform:
   - WRONG:
     `useTransform(progress, [0, 0.5, 1], ["calc(-50% + 10vw)", "calc(-50% + 0vw)", "calc(-50% + -20vw)"])`
     Framer Motion's string tokenizer crashes on `+ -` and units switching.
   - CORRECT:
     Use a pure JS mathematical function inside `useTransform(progress, (p) => { ... })`
     and compute the exact number before returning `calc(-50% + ${x.toFixed(2)}vw)`.

2. Opacity Alone Leaves Ghost Hitboxes:
   - When fading out the 7 background cards, setting `opacity: 0` keeps their DOM elements
     clickable and hovering over Section 01.
   - ALWAYS apply:
     `display: useTransform(scrollYProgress, (p) => p > 0.44 ? "none" : "block")`.

3. Z-Index Layering Order:
   - Z-Index 2: Canvas Firefly Layer (behind all cards, above void background)
   - Z-Index 10: Hero Cards container
   - Z-Index 20: Editorial Section 01 text container
   - Z-Index 30: Hero Center Headline ("A photograph keeps a moment...")
     * Container must have `pointer-events: none`, child text `pointer-events: auto`.
     * Must be strictly above the scattering cards so text is never obscured!
   - Z-Index 35: Focal Card (elevated when scrollYProgress exceeds 0.40)

4. Mobile & Touch Screen Adaptations:
   - Check `window.matchMedia("(pointer: coarse)")` rather than only viewport width.
   - On touch devices, disable mouse parallax.
   - DestX = 0, DestY = 18vh, midScale = 1.35 (instead of desktop 1.85).
   - Fall back to clean single-column layouts for Section 01 and Section 02.
